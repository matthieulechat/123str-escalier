# BLK-010 — `pnpm add` bloqué par `minimumReleaseAge`

| Friction | Cause réelle | Solution | Statut |
| --- | --- | --- | --- |
| `pnpm add @fontsource-variable/archivo @fontsource/dm-mono` (et `pnpm remove @fontsource-variable/geist`) échouent : `ERR_PNPM_NO_MATURE_MATCHING_VERSION`. | La résolution réinstalle `vite@8.3.4` → `rolldown@1.2.14`, publié 2 jours avant, sous le seuil `minimumReleaseAge`. Réglage non contourné volontairement. | Archivo + DM Mono chargées via Google Fonts dans `index.html`. Reste à faire dans quelques jours : `pnpm remove @fontsource-variable/geist` (dépendance inutilisée), éventuellement passer les polices en fontsource pour le hors-ligne PWA. | ouvert |
