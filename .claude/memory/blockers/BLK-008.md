# BLK-008 — `pnpm add three` : EPERM au renommage de `package.json`

| Friction | Cause réelle | Solution | Statut |
| --- | --- | --- | --- |
| La dépendance s'installait dans `node_modules` mais `package.json` restait inchangé (EPERM sur le rename du fichier temporaire). | Fichier probablement verrouillé un instant par le serveur de dev d'une autre session (Windows). | Relancer `pnpm add` a suffi ; vérifier `package.json` après chaque install sous Windows. | résolu |
