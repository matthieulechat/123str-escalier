# LRN-010 — Bash : `node -e "…"` expande backticks et `${}`, passer par Edit

**Pattern observé** : Un script `node -e "…"` entre guillemets doubles qui contient des template literals TS voit ses backticks et `${…}` interprétés par bash (substitution de commande) : le code écrit est tronqué en silence, avec seulement des erreurs du type « No such file or directory ».

**Contexte** : Deux tentatives de réécriture de `src/dxf.ts` via node ont produit un fichier invalide (`'40', , '1'`) ou rien du tout ; un heredoc non protégé avec apostrophes a ensuite fait échouer tout un bloc d'écriture mémoire.

**Application future** : Modifier du code TS/JS contenant des backticks avec l'outil Edit/Write ; réserver `node -e` aux scripts sans template literal ; tout texte libre (apostrophes françaises) passe par Write, pas par Bash. Voir aussi [LRN-005](LRN-005.md).
