# LRN-013 — Halo SVG `stroke="#fff"` visible dès que le fond change

| Pattern observé | Contexte | Application future |
| --- | --- | --- |
| Un texte SVG lisible sur les traits grâce à `paint-order="stroke"` + `stroke="#fff"` dessine un rectangle blanc autour du texte dès que le fond n'est plus blanc. Relier le halo au fond via `style={{ stroke: 'var(--card)' }}` : la propriété CSS accepte `var()`, l'attribut de présentation ne le fait pas de façon fiable. | Passage du thème neutre (fond blanc) au thème Cordeau : Baptiste a vu du blanc autour des étiquettes (`src/components/Annot.tsx`). | À chaque changement de thème, chercher `#fff` / `white` dans les SVG et lier les halos à la variable du fond qui les porte. |
