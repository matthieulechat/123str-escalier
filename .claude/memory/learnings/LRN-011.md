# LRN-011 — Bloc UI nommé : chercher par titre affiché, pas composant

| Pattern observé | Contexte | Application future |
| --- | --- | --- |
| Quand Baptiste nomme un bloc de l'interface, il cite son titre affiché, qui peut n'être qu'une partie d'un composant. | « Le tableau des valeurs » désignait le volet *Tableau des valeurs par contremarche*, rangé dans `Results.tsx` avec les cartes de synthèse ; déplacer `Results` entier a déplacé les cartes à tort, deux fois. | Avant de déplacer un bloc, greper le libellé cité dans les `title` / textes affichés ; s'il partage un fichier avec autre chose, l'extraire dans son propre composant (ici `ValuesTable.tsx`). En cas de doute, demander quel bloc. |
