# LRN-005 — Heredocs Bash avec apostrophes : « unexpected EOF »

| Pattern observé | Contexte | Application future |
| --- | --- | --- |
| Dans le Bash tool sous Windows, une grosse commande enchaînant plusieurs `cat <<'EOF'` (ou un `node - <<'EOF'`) contenant beaucoup d'apostrophes françaises échoue avec « unexpected EOF while looking for matching `'` », même avec un délimiteur entre guillemets. | Deux échecs : création des registres mémoire en un seul appel, puis réécriture de `src/stair.ts` par script. C'est l'inverse du contournement de GLRN-275, où le heredoc débloquait un Write refusé. | Pour plusieurs fichiers ou un long script : un appel Write par fichier, ou écrire le script de transformation dans un fichier `.cjs` du scratchpad puis l'exécuter avec `node`. |
