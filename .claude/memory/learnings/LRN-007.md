# LRN-007 — `perl -0pi` multi-lignes pour refactorer du JSX : à éviter

**Pattern observé** : Les regex `perl -0pi` multi-lignes ont abîmé du JSX à deux reprises : `$_` resté littéral dans un remplacement `/e` (balises `<span>` perdues), et un bloc déplacé en tête de fichier. Correction manuelle nécessaire à chaque fois.

**Contexte** : Conversion des wrappers `<figure>` / `<details>` et des contrôles de `Saisie/index.tsx` vers shadcn.

**Application future** : Pour un refactor JSX multi-lignes : Edit ou réécriture complète avec Write. Réserver `sed` aux remplacements d'une seule ligne (imports, noms de classes). Voir aussi [LRN-005](LRN-005.md).
