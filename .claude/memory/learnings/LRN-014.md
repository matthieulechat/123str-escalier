# LRN-014 — Satori n'affiche pas un `<img>` SVG : passer le logo en PNG

**Pattern observé** : Satori ne décode que PNG / JPEG / GIF dans `<img>`. Rendre d'abord le logo SVG en PNG avec `new Resvg(svg, { fitTo: { mode: 'width', value: 280 } }).render().asPng()`, puis le passer en data URI PNG, dans le même script que le rendu de l'og:image.

**Contexte** : Génération de `public/og-image.png` (template Logo) avec le logo `public/icon.svg`.

**Application future** : Tout rendu og:image Satori qui inclut un logo SVG : conversion resvg → PNG avant l'arbre Satori ; polices en `.woff` (voir aussi GLRN-145).
