# LRN-020 — Lire un DWG R2018 sans AutoCAD : libredwg-web en Node

| Pattern observé                                                                                                                                                                                                                                                                                                                                                                                                                                | Contexte | Application future |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- | ------------------ |
| `npm i @mlightcad/libredwg-web` dans un dossier du scratchpad, puis en Node : `LibreDwg.create('./node_modules/@mlightcad/libredwg-web/wasm/')`, `dwg_read_data(buf, Dwg_File_Type.DWG)`, `convert()` → objet complet (tables, header, entités). `JSON.stringify` exige un replacer pour les `BigInt`. Les entités des blocs sont dans `tables.BLOCK_RECORD.entries[].entities` ; le texte MTEXT garde ses codes de formatage (`\pxqr;{\fArial | b1       | i1                 | …;B}`) à retirer avant de filtrer. Pour retrouver un symbole, partir d'une ligne connue (par calque) et lister les entités proches de ses extrémités. | DWG AC1032 (binaire compressé) du bureau à analyser sur le PC perso de Baptiste, sans AutoCAD ni ODA. A permis de relever hauteur, style, oblique et positions exactes des numéros et des bouts de coupe. | Pour reproduire une convention de dessin d'un DWG : lire le fichier ainsi plutôt que demander des mesures à Baptiste. Écrire les scripts d'analyse dans des fichiers `.cjs` (pas `node -e` avec regex et antislashs). |
