# LRN-008 — Texte DXF plus large dans AutoCAD que dans un aperçu SVG

**Pattern observé** : Un TEXT DXF de hauteur h est rendu bien plus large dans AutoCAD (« 05 » en italique ≈ 1,9 h de large) que dans un aperçu SVG en police navigateur. Les écarts calibrés sur l'aperçu donnent des textes qui touchent les traits.

**Contexte** : Numéros de marche du plan : deux itérations d'écarts fixes ont échoué avant de mesurer la boîte sur la capture AutoCAD de Baptiste.

**Application future** : Dimensionner toute boîte de texte DXF depuis une capture du rendu AutoCAD réel (largeur ≈ 1 h par caractère + inclinaison), jamais depuis l'aperçu.
