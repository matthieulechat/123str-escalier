# LRN-019 — Bash bloqué 120 s : `cat > fichier` sans heredoc attend l'entrée

**Pattern observé** : Une ligne `cat > fichier` sans heredoc ni redirection d'entrée attend stdin : la commande ne rend jamais la main, passe en arrière-plan au bout de 120 s et bloque toutes les commandes qui suivent dans le même appel.

**Contexte** : Ligne parasite glissée dans une commande composée (édition + check + lint + génération d'aperçu) : rien n'a tourné après elle.

**Application future** : Arrêter la tâche avec `TaskStop`, vérifier ce qui a été appliqué avant la ligne fautive, puis relancer sans elle ; écrire les fichiers temporaires avec un heredoc `<<'EOF'` ou l'outil Write.
