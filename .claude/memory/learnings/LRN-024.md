# LRN-024 — Cotes R12 minuscules dans un gabarit annotatif : surcharge DSTYLE

**Pattern observé** : À l'insertion d'un DXF dans un dessin qui a déjà le style de cote du même nom, la définition du dessin cible l'emporte. Un style annotatif a `DIMSCALE 1` : des cotes R12 (non annotatives) sont redessinées à l'échelle 1, donc minuscules. Correctif : xdata sur chaque `DIMENSION` — `1001 ACAD`, `1000 DSTYLE`, `1002 {`, `1070 40`, `1040 20`, `1002 }` — plus une table `APPID` contenant `ACAD`. La cote garde le reste du style du gabarit (police, flèches, lignes d'attache fixes).

**Contexte** : Export DXF des cotes globales, inséré dans le gabarit ABAK du bureau (cotes `ABAK_BA` annotatives à 1:20).

**Application future** : Pour simuler le gabarit sans AutoCAD : ezdxf, forcer `doc.dimstyles.get('ABAK_BA').dxf.dimscale = 1`, puis lire `DimStyleOverride(d).get('dimscale')` sur chaque cote.
