# LRN-009 — Texte sans collision : recherche en grille + test segment/boîte

| Pattern observé | Contexte | Application future |
| --- | --- | --- |
| Pour poser un texte près d'une cible sans toucher aucun trait : générer des positions candidates en grille (distance le long + distance latérale), les trier par distance à la position idéale, garder la première dont la boîte (marge comprise) ne coupe aucun segment déjà tracé — test segment/rectangle par découpage de Liang-Barsky. Les tests se font dans le repère final, donc ça reste juste quand la vue tourne et que le texte reste horizontal. | `src/dxf.ts`, numéros de marche entre foulée et jour, 4 orientations ; vérifié sur 5 escaliers sans aucun contact. | Réutiliser `hitsBox` + la grille pour toute étiquette automatique (cotes, repères) en DXF ou SVG ; accompagner d'un script qui recontrôle les collisions sur le fichier généré. |
