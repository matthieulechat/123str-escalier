# LRN-003 — Aperçu Claude refuse la CA mkcert fraîchement installée

| Pattern observé | Contexte | Application future |
| --- | --- | --- |
| Après un `mkcert -install` réussi (CA présente dans le magasin Root utilisateur, vérifiable avec `certutil -user -store Root`), l'aperçu intégré de l'app Claude renvoie toujours `ERR_CERT_AUTHORITY_INVALID`, probablement parce qu'il charge les autorités au démarrage. Côté curl (schannel), l'erreur `CRYPT_E_NO_REVOCATION_CHECK` (code 35) est normale : les certificats mkcert n'ont pas de liste de révocation. | Vérification de l'aperçu HTTPS après installation de `vite-plugin-mkcert`. Voir aussi GLRN-251 (même blocage avec agent-browser en headless). | Tester le certificat avec `curl --ssl-no-revoke` plutôt que `curl -k`. Pour l'aperçu intégré, rester en HTTP ou redémarrer l'app après `mkcert -install`. |
