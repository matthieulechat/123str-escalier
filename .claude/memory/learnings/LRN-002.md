# LRN-002 — Chevauchement SVG détecté via getBoundingClientRect

**Pattern observé** : Étiquettes rangées dans les marges gauche/droite et empilées (composant `Labels`), puis contrôle automatique : comparer les `getBoundingClientRect()` de tous les `<text>` et vérifier qu'ils restent dans le SVG, pour chaque combinaison de saisie.

**Contexte** : Captures d'écran impossibles quand la fenêtre d'aperçu est masquée ; les étiquettes placées en rayon se chevauchaient.

**Application future** : Rejouer le script JS sur les 12 combinaisons (type × sens × jour) après toute modification de schéma. Limite : ne détecte pas les croisements texte ↔ trait.
