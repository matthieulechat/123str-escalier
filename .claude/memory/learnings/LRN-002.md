# LRN-002 — Chevauchement SVG détecté via getBoundingClientRect

**Pattern observé** : Étiquettes rangées dans les marges gauche/droite et empilées (composant `Labels`), puis contrôle automatique : comparer les `getBoundingClientRect()` de tous les `<text>` et vérifier qu'ils restent dans le SVG, pour chaque combinaison de saisie.

**Contexte** : Captures d'écran impossibles quand la fenêtre d'aperçu est masquée ; les étiquettes placées en rayon se chevauchaient.

**Application future** : Rejouer le script JS sur les 12 combinaisons (type × sens × jour) après toute modification de schéma. Croisements texte ↔ trait (ajout 2026-10-17) : échantillonner chaque `<path>` tous les 3 px avec `getPointAtLength` puis `new DOMPoint(x, y).matrixTransform(path.getScreenCTM())`, et tester si un point tombe dans le rect d'un champ HTML ; même script pour le débordement (rect hors carte) et l'écart mini entre champs, sur type × orientation × sens, à deux largeurs (1024 et 1440 px).
