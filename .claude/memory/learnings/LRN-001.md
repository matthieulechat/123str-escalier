# LRN-001 — Méthode de la herse réduite à une formule fermée

| Pattern observé | Contexte | Application future |
| --- | --- | --- |
| AB = collet à balancer c, AC = foulée à balancer a, D sur BC avec AD = AB. Avec t = 2c² / (a² + c²), le collet cumulé du giron x vaut λ = c·x / (x(1 − t) + a·t). | Le site web4me n'explique la méthode qu'en images. La formule est validée au centième sur leur feuille Excel (22,90 / 41,63 / 57,22 / 70,42 / 76,00). | Fonction `herse()` dans `src/stair.ts`, testée dans `stair.check.ts`. Un nez posé sur la ligne de séparation compte pour les deux moitiés (symétrie). |
