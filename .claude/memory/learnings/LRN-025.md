# LRN-025 — Cotes automatiques : angles visibles + côté tourné dehors

**Pattern observé** : Pour coter un contour sur ses 4 côtés : nettoyer d'abord le contour (sans points doubles ni points alignés, sinon un prolongement coupe un côté en deux), garder les angles de plus de 20° (les points d'arc sont exclus), puis, pour chaque côté, les angles dont le rayon vers l'extérieur ne rencontre aucun autre segment **et** qui bordent un segment parallèle à la cote, lui-même visible (son milieu passe le même test). Plus de 2 points → une chaîne, puis la cote totale un rang plus loin.

**Contexte** : `src/dxf.ts`, cotes globales en droit, quart et demi-tournant, jour droit ou arrondi. Sans le test « côté tourné dehors », le débord de 1 cm d'une contremarche brute apparaissait dans la cote du côté opposé.

**Application future** : Réutilisable pour toute cotation automatique d'un plan (DXF ou SVG) ; travailler dans le repère final, quand la vue est tournée par multiples de 90°.
