# LRN-023 — Overlay HTML vertical : coller un bord au point d'ancrage

**Pattern observé** : Pour tourner un champ HTML posé en absolu sur un schéma et le coller à côté d'une cote verticale : `transform: translate(-50%, -50%) rotate(-90deg) translateY(±50%)`. Le dernier `translateY` s'applique dans le repère déjà tourné et prend 50 % de la hauteur propre de l'élément : il pousse le champ à gauche (`-50%`) ou à droite (`+50%`) du point, bord collé, quelle que soit sa taille ou la largeur d'écran. Une simple classe `-rotate-90` le laisse centré sur le point et il mord sur le dessin.

**Contexte** : `Saisie/Field.tsx` (prop `vertical: 'left' | 'right'`) ; `PlanSchema` ancre au milieu de la ligne de cote, côté de l'étiquette (donc hors du dessin), dès que la cote est verticale après rotation.

**Application future** : Toute étiquette HTML pivotée sur un SVG ; garder l'ancre sur la ligne de cote et choisir le côté par position de l'étiquette d'origine.
