# LRN-022 — Retour « rendu faux » : vérifier d'abord la version du fichier

**Pattern observé** : Avant de corriger un rendu jugé faux, comparer une valeur caractéristique du fichier testé avec ce que le code actuel produit : ici une hauteur de texte de 4,4 (ancienne formule `taille / 50`) contre 6 fixe dans le code. Le fichier venait d'un ancien code : modifications ni commitées ni déployées, et l'app est une PWA dont le service worker sert l'ancien bundle.

**Contexte** : Baptiste trouvait les numéros « trop petits » et l'oblique faux ; la palette Propriétés de CadCraft a révélé la hauteur 4,4.

**Application future** : Demander tôt la valeur d'une propriété mesurable (palette Propriétés), et rappeler `pnpm dev` + Ctrl+F5 pour tester un changement non déployé.
