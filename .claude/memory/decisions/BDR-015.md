# BDR-015 — Coupes : une par mur extérieur, à 20 cm, regard vers le jour

| Décision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | Pourquoi                                                                                                                                     | Alternatives considérées                                                                                                                                                              | Statut |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Une ligne de coupe par segment du mur extérieur (`outerLine`), parallèle au mur et décalée de `CUT = 20` cm vers l'intérieur ; lettres A, B, C… dans le sens de la montée ; flèches de regard vers le jour. Droit : 1 coupe, quart : 2, demi : 3 (dont le mur du fond). Le moteur (`cutLines()`, `cutProfile()` dans `src/stair.ts`) sert le plan et l'export DXF. Dans le DXF, les coupes sont sur une ligne sous les 4 vues en plan, en miroir pour le sens « droite » afin de garder le regard vers le jour. Sur le plan écran, les lignes débordent de 3,5 fs pour passer au-delà des cotes. | Demande de Baptiste (« une coupe à 20 cm de chaque bord extérieur ») ; une seule géométrie partagée évite que le plan et l'export divergent. | Lignes rapprochées sous les cotes (0,6 fs) : refusé, Baptiste préfère qu'elles dépassent ; coupe côté jour en escalier droit : non retenue (le jour n'est pas un mur dans le modèle). | actif  |
