# BDR-006 — Export DXF R12 généré dans le navigateur, pas de DWG

| Décision | Pourquoi | Alternatives considérées | Statut |
| --- | --- | --- | --- |
| Le bouton « Export DXF » du plan produit un DXF R12 ASCII (`src/dxf.ts`), en entités `LINE`, `SOLID` et `TEXT` uniquement, sans table de calques ni de types de ligne. Le dessinateur l'ouvre ou l'insère dans AutoCAD, puis l'enregistre en DWG si besoin. | Le DWG est un format binaire fermé (AC1032) qu'on ne peut pas écrire sans bibliothèque lourde ; AutoCAD lit le DXF nativement. Sans table, les calques du gabarit du bureau apportent type de ligne et épaisseur à l'insertion. | Lib DWG (lourde, payante ou WASM) ; DXF récent avec LWPOLYLINE et tables (plus de code sans gain). | actif |
