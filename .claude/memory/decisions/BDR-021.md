# BDR-021 — Fichier de paramètres = StairInput brut en JSON

**Décision** : L'export écrit l'objet `StairInput` tel quel dans `escalier.json`. À l'import, le JSON est fusionné par-dessus `DEFAULTS` (`{ ...DEFAULTS, ...data }`), sans schéma ni numéro de version. Les choix visuels (orientation du plan, cases de la vue 3D) ne sont pas exportés. Le bouton Imprimer est retiré, l'impression passe par Ctrl+P.

**Pourquoi** : Un nouveau champ ajouté à `StairInput` prend sa valeur par défaut, donc les anciens fichiers restent lisibles sans migration. Une valeur aberrante est déjà signalée par l'erreur de `computeStair`.

**Alternatives considérées** : validation Zod champ par champ, fichier versionné avec migrations — écartées, inutiles tant que les champs ne sont pas renommés. ⚠️ Renommer ou supprimer un champ de `StairInput` casse les fichiers existants sans prévenir : il faudra alors ajouter une migration.
