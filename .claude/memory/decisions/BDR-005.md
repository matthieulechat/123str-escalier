# BDR-005 — UI sur shadcn/ui base-nova, thème neutre provisoire

| Décision | Pourquoi | Alternatives considérées | Statut |
| --- | --- | --- | --- |
| Toute l'UI passe par `src/components/ui/` (shadcn base-nova) : Card, Button, Input, Label, NativeSelect, Checkbox, Alert, Badge, Table, Collapsible. Variantes ajoutées dans les composants (badge `success`, alert `warning`, input `sm`) ; enveloppes partagées `FigureCard` / `CollapsibleCard` dans `src/components/Section.tsx`. Les couleurs des schémas SVG (brut / fini / balancé) restent en dur, ce sont des codes métier. Thème `neutral` par défaut : les tokens « Mètre ruban » ne sont pas encore appliqués. | Demande de Baptiste : remplacer le Tailwind fait main sur éléments natifs par des composants homogènes. | Garder les classes Tailwind sur `<button>` / `<input>` / `<details>` natifs — écarté ; `Select` base-ui au lieu de `NativeSelect` — écarté, le natif suffit. | actif |
