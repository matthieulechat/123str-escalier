# BDR-016 — Calques des coupes DXF : CA / COFFRAGE-VU / ABAK_A-AXE

| Décision                                                                                                                                                                                                                                                                                                         | Pourquoi                                                                                                                                               | Alternatives considérées                                                                                                               | Statut |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Dans les coupes : profil fini → `ABAK_BC-COFFRAGE-CA` ; béton brut et sous-face → `ABAK_BC-COFFRAGE-VU` ; traits de fin de coupe (du dessous du béton jusqu'au-dessus de la finition, qu'ils coupent) → `ABAK_A-AXE`. Sur les vues en plan, lignes de coupe et flèches → `ABAK_A-AXE`, lettres → `ABAK_A-ANNOT`. | Conventions données par Baptiste ; « ABAK-CO » demandé pour le brut, confirmé ensuite comme `ABAK_BC-COFFRAGE-VU`, et nom exact `ABAK_A-AXE` confirmé. | Lignes de coupe sur `ABAK_A-COTA` (première version, remplacée) ; fermetures des planchers sur le calque du brut (remplacé par l'axe). | actif  |
