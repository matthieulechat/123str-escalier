# BDR-013 — Saisie dans un CollapsibleCard ouvert, nommé region

**Décision** : Toute la saisie (titres Configuration, Plan — dimensions, Coupe — niveaux et finitions) est dans le `CollapsibleCard` partagé de `src/components/Section.tsx`, titre « Saisie de l'escalier », ouvert par défaut. `CollapsibleCard` reçoit une prop optionnelle `regionLabel` qui pose `role="region"` + `aria-label` sur la carte, pour garder le repère navigable des lecteurs d'écran.

**Pourquoi** : Même bouton et même chevron que les autres volets (Herse, Lexique, Tableau des valeurs) ; une carte dans la carte aurait été redondante ; le repère `region` existait sur l'ancienne `Card` et serait perdu sans l'option.

**Alternatives considérées** : `Collapsible` maison sur la seule ligne Configuration (première version, remplacée) ; `Card` imbriquée dans un `CollapsibleCard` ; abandon du repère `region`.
