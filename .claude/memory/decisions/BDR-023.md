# BDR-023 — Cotes globales DXF : vraies DIMENSION au style ABAK_BA

**Décision** : Les cotes globales du plan fini sont des entités `DIMENSION` R12 linéaires (70 = 0, rotation 0/90°), étirables, chacune avec son bloc anonyme `*Dn` qui reproduit l'exemple : lignes d'attache de longueur fixe 13 (10 côté objet, 3 au-delà), trait oblique 2,6 à 45°, texte Tahoma 5 à 4,6 au-dessus, rangées tous les 16 (chaîne puis total sur les 4 côtés). Le DXF ajoute une section `BLOCKS` et les tables `APPID` (`ACAD`) et `DIMSTYLE` `ABAK_BA` (échelle 20, `DIMTSZ` 0.13, `DIMRND` 0.1, `DIMZIN` 8), plus une surcharge `DIMSCALE 20` par cote. Le plan brut n'a aucune cote. Les lignes de coupe sont prolongées au-delà des cotes en vue finie. Exception à [BDR-006](BDR-006.md).

**Pourquoi** : Baptiste veut des cotes qu'il peut étirer ; validé sur son gabarit (taille correcte après surcharge).

**Alternatives considérées** : Lignes et texte éclatés (livrés puis refusés) ; DXF 2018 avec cotes annotatives (beaucoup de code de format sans gain).
