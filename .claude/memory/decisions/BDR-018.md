# BDR-018 — Export DXF : plan brut à droite du plan fini

**Décision** : L'export DXF ajoute, entre les 4 plans finis et les coupes, une ligne des mêmes 4 orientations en brut : pas de contremarches finies (`COFFRAGE-CA`), ni ligne de foulée, ni numéros ; 1re et dernière CM brutes sur `COFFRAGE-VU`, CM intermédiaires sur `COFFRAGE-FIN` en couleur du calque (pas de couleur 7 forcée, contrairement au plan fini). Dans toutes les vues en plan, les limons sont prolongés jusqu'à la dernière CM brute (qui dépasse le nez de palier fini de l'épaisseur de finition) pour fermer l'escalier.

**Pourquoi** : Demandes de Baptiste : une vue de coffrage brute prête à l'emploi pour le dessinateur, et un contour fermé en brut.

**Alternatives considérées** : Masquer la finition sur la vue unique : non retenu, les deux vues servent ensemble ; prolonger les limons dans le moteur (`outerLine`) : écarté, cela aurait décalé les lignes de coupe.

**Mise à jour 2026-10-17** : une seule orientation exportée ([BDR-020](BDR-020.md)) ; le plan brut est posé à droite du plan fini, sur la même ligne, et les coupes remontent juste dessous.
